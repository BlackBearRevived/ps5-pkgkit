## PS5Upload

The package format, the reference writer this project reproduces, and the
Kraken encoder and block layout are ported from [ps5upload](https://github.com/phantomptr/ps5upload)
(revision `4174eee2319d45a488c37832a5b890de2f9c5358`), which is GPL-3.0-or-later.
Its author records parts of that work as ported or derived from PS5 Dump Forge
(GPL-3.0-or-later with the UnRAR exception) and from ps5-payload-dev's tools.

## Key material

`src/ps5_pkg/format/keys.py` vendors the fixed debug-package constants that
reference uses (RSA public moduli, the debug RIF key pair, the keystone HMAC
keys and the `naps_meta_18` AES-XTS keys). ps5upload records that they came from
LibProsperoPKG's key data and that their use is a deliberate distribution
decision. They are debug/test material, not retail production keys. The file is
generated by `tools/import_keys.py` from the reference checkout and can be
replaced from that one place.
